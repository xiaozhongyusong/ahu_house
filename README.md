# 🐱 校园网小助手

安大 Dr.COM 校园网自动登录工具，萌系马卡龙界面，后台自动保持在线。

## ✨ 功能特点

- 🔄 开机自动登录，掉线自动重连
- 🎨 萌系马卡龙 UI，软萌语气
- 📊 实时状态面板：认证状态 / 外网探测 / 计划任务
- 🔒 密码用 Windows DPAPI 加密存储，只在本机可解密
- ⏱️ 每分钟自动检查，掉线立刻重连
- 🛡️ 连续失败自动冷却，不会疯狂重试

## 📁 文件说明

```
├── 01-首次设置.vbs      ← 第一次用双击这个
├── 02-立即检查.vbs      ← 手动触发一次检查
├── 03-更新账号密码.vbs  ← 改密码用这个
├── 04-停用自动登录.vbs  ← 暂时关掉
├── 05-查看状态.vbs      ← 打开状态面板
├── 06-清除保存凭据.vbs  ← 删掉密码
├── 程序/                ← 核心代码
└── 数据/                ← 存密码和日志（已 gitignore）
```

## 🚀 使用方法

1. 双击 `01-首次设置.vbs`
2. 输入完整账号（一般是 `学号@telecom`）和密码
3. 点保存就完事了，之后开机自动连

## 🛠️ 技术栈

- PowerShell 5.1 + WinForms
- Dr.COM 网关协议自动识别
- Windows 计划任务做定时触发
- DPAPI 加密存储凭据
